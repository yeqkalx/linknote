## 2. 改动

### Relay（`relay/`）
- 只在存在手机 socket 时 `setAlarm`；无手机时不 ping、不写心跳 SQL；手机断开 `deleteAlarm`。
- `last_seen` 只存内存；`online/last_seen_at/ready/issues` 仅在跃迁/变化时合并写 1 条 SQL。
- 手机连上时对 Agent 做 `ping`+`probe` 探活（3s 超时）；有手机期间 30s alarm 兜底离线（最坏 60–93s）。
- `ack_note.persisted`：`false` 不删 `undelivered_notes` 并转发 Agent `false`；缺省 `true` 兼容旧客户端。
- `agent_ready {ready, issues[]}`：透传到手机 `hello`/`presence` 与 REST `/agent/me` 顶层。
- **修复 `intVar` 缺省值 bug**：未配置 `WS_*` 时原先回落到最小值（生产 v0.2 alarm 实际 1s），v0.3 恢复 30s。
- 测试：`npm test` **51/51**，`npm run typecheck` 通过。

### PC Agent（`pc-agent/`）
- 删除 25s 应用层 JSON ping，改用 WebSocket 协议 ping（`ping_interval=25` / `ping_timeout=20`）；保留对服务端 `ping` 的 `pong` 与 `probe` 的 `probe_ack`。
- 新增 `readiness.py`：`model_not_configured` / `engine_unreachable`（health 2s 超时、30s 缓存、404 回退 `/get_all_providers`）。
- `ack_note.persisted`：true 清 outbox；false 保留并按 30s/2min/10min 最多重发 3 次；notes/ 文件始终保留。
- 测试：`pytest` **222 passed**（原 206 + 新增 16）。

### 手机 PWA（`app/www/`）
- 保存成功才 ack `persisted:true`；失败 ack `false` 并提示“未保存到手机，可重试”。
- 笔记缓存 30 篇 / 6MB、`navigator.storage.persist()`、收藏不淘汰、列表徽标“已保存到手机/需从电脑取回”。
- readiness：顶部胶囊/电脑卡显示“在线 · 可生成 / 在线 · 需要处理 N 项”，点开展开 issues。
- 阅读器底部改为 复制 / 导出（下载+分享）/ 更多（固定、重新生成、移除、重试保存）；失败页“重新生成”提示会重新调用模型。
- 首页去掉重复在线信息、最近任务靠前、输入可折叠、空态示例笔记；任务页三态摘要 + 阶段折叠、无假百分比。
- 测试：官方 `scripts/ui-smoke.mjs`（真实 v0.3 Relay）**10/10 PASS**；v0.3 mock E2E 41/41。

### 桌面端（`desktop/`）
- 一级导航缩为 **笔记库 / 任务 / 设备 / 设置**；原 AI 模型/语音/引擎/日志改为设置页入口（二级页可返回）。
- 顶部就绪横幅：“已准备好接收视频” / “需要处理：未配对/Agent 未运行/引擎未运行/ffmpeg 缺失/模型未配置”。
- 笔记库：搜索（标题/平台）、预览、打开原文件/目录、复制路径与 Markdown。
- 设备页：配对面板常驻 + Relay/Agent/引擎连接卡；配对成功后设备列表常驻。
- 设置页新增“笔记自动归档”：选 Obsidian/本地目录、开关、立即导出、打开目录；归档补 YAML frontmatter（title/source_url/platform/created_at/model/app_version），幂等。
- FFmpeg 默认下载改为 BtbN LGPL shared（约 78MB zip / 177MB 解压），安装包附带 GPLv3/LGPLv3 全文；不再默认下载 gyan GPL 构建。
- 版本 0.3.0；测试：`_smoke` **84 项**、pytest **17 passed**。
- 打包：MSI 安装/升级（0.2.2→0.3.0 数据保留）/卸载/Finish 启动/许可文件/冻结包 websockets+ffmpeg URL 检查全部通过。

## 4. 未验证 / 已知限制

- **未做代码签名**：SmartScreen 会提示未知发布者；分发用 MSI（本机 Inno EXE 仍被安全软件拦，exit 5）。
- **Android APK 未真机验证**：无真机/模拟器；仅静态校验（包名、版本、分享入口、assets 一致性、debug 签名）。
- PWA 已安装旧版本用户需要重开一次页面让 SW 0.3.0 接管（`CACHE_REVISION=2` 会清旧壳缓存）。
- FFmpeg 首启需要访问 GitHub/BtbN（约 78MB）；网络不可达时用“跳过/手动指定本机 ffmpeg”。
- 联想电脑管家可能删除 HKCU Run 自启项（第三方行为；MSI 写入本身正确）。
- ToS/版权风险未处理（用户明确暂缓）；平台下载能力由 BiliNote 与用户自行承担。
