## 2. 改动

### 自托管 Relay（默认地址清空）
- `pc-agent`：`DEFAULT_RELAY_BASE_URL=""`；未配置时 `run`/`pair` 不连接任何公共地址，打印中文指引并退出；`status` 显示“Relay：未配置”。
- Desktop：默认 Relay 空；首次向导新增第 2/8 步「连接 Relay」——输入自己的 URL，测试 `/api/v1/health`（校验 `ok` + `realtime`），可稍后配置但配对按钮禁用；就绪横幅新增“未配置 Relay”阻塞项。
- 旧配置迁移：命中作者旧域名 / 旧 workers.dev 默认 / 旧占位符时自动清空并提示重填；自定义 URL 保留。
- PWA：原生 APK/非同源必须手填自己的 Relay；PWA 与 Relay 同源时仍用 `location.origin`。
- APK：默认 Relay 为空；解包扫描确认无作者域名。
- Relay：`wrangler.toml` 去掉作者自定义域名路由、真实 D1 id/生产域名；改为占位符 + 注释；部署文档见 [自托管 Relay](../docs/self-hosting.md)。

### 删除 QQ Bot
- 删除 `pc-agent/linknote_agent/bots/qq.py`、QQ 配置（`qq_*`）、QQ state/runner 分支、QQ 测试。
- 桌面删除 QQ 消息入口、`test_qq_bot`、`qq_*` 配置与用例。
- Relay 删除 `qq` 设备平台（现在 `android|ios|web|telegram`）。
- README/文档只保留 Telegram Bot。

### 保留
- Telegram Bot（本机 `getUpdates` 长轮询）：自己的 Bot Token、凭证只存本机、不上传 Relay；完成后预览 + 完整 `.md`。
- 页面/任务/笔记管线、缓存、readiness、桌面 4 导航、归档、FFmpeg LGPL shared、许可文本均沿用 v0.4。

## 4. 未验证 / 已知限制

- 按要求**未在本机安装 0.5.0、未部署 Relay、未做真实 Telegram/BiliNote 端到端**；由用户部署自己的 Relay 后验证。
- 用户必须自己部署 Cloudflare Relay（免费额度个人够用；公开服务需加限流/条款）。
- Telegram 在中国大陆通常需自备网络；Bot 不要公开分享（谁发消息谁能用你的电脑）。
- APK 为 debug 签名且未真机验证；MSI 未做代码签名。
- 旧版本用户升级：旧 Relay 地址会被清空，需要按向导重填自己的 Relay。
