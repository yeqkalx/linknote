# v0.5.0 变更规格：自托管 Relay + 只保留 Telegram Bot

> 用户决定：
> 1. **Release 不再使用作者自己的域名/Cloudflare**；每个用户绑定自己的 Cloudflare 账号 + 域名部署 Relay，客户端首次配置时填入自己的 Relay 地址。
> 2. **删除 QQ Bot**，只保留 Telegram Bot（本机长轮询）。

## 1. 目标与硬约束

- 源码、安装包、APK、文档中**不得再出现作者的生产域名 `<author-domain>`**（示例统一用 `https://your-relay.example.com` 或 `<your-relay>`）。
- 客户端**默认 Relay 为空**：未配置时不得连接任何公共地址；必须由用户填写自己的 Relay。
- Relay 的 `wrangler.toml` 不包含作者账号专属配置（自定义域名路由、真实 D1 database_id、生产 PUBLIC_BASE_URL/ALLOWED_ORIGINS），改为占位符 + 部署文档。
- QQ Bot 相关代码/配置/UI/测试/文档全部删除；Telegram Bot 保留并只依赖本机配置的 Relay。
- 版本：Desktop **0.5.0**；PWA **0.4.0**；APK versionCode **4** / versionName **1.3**；Relay `RELAY_VERSION` **0.5.0**（仅代码，不部署到作者旧域名）。

## 2. pc-agent（agent-dev）

### 2.1 默认 Relay
- `DEFAULT_RELAY_BASE_URL: str = ""`（原来作者生产地址）。
- 新增 `AgentConfig.relay_configured`（`bool(relay_base_url.strip())`）。
- `run`/`pair`/`status` 遇到空 Relay：
  - 给出明确中文错误：`还没有配置 Relay 地址。请先按 docs/self-hosting.md 部署自己的 Cloudflare Relay，然后在桌面「设置/首次向导 → Relay」填入 https://你的域名`；
  - `pair` 支持 `--relay` 指定；`run` 不连接任何默认地址，退出码非 0（2 也可）。
- `status` 显示 `Relay：未配置`。
- CLI help/README 更新；`pc-agent/README.md` 去掉作者域名、补自托管说明。

### 2.2 删除 QQ Bot

- `bots/device_relay.py`：仅保留通用 device 方法（Telegram 用）。
