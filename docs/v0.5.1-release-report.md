## 2. 改动

- **pc-agent**：新增 `local_mode` BotRunner。
  - 无 Relay + Telegram 启用 + token 非空时，`run` 进入“Telegram 本地模式（无 Relay）”：不创建 RelayClient、不连 WS、不需要配对手机。
  - Bot 收链接 → 本机 `TaskPipeline` 直接调 BiliNote → 本机 `notes/local-<id>.md` → 回发 Telegram。
  - 本地任务串行、`/status /last /retry` 适配本地状态；重启时未完成任务标记失败，可重发/重试。
  - 有 Relay 时保持原 Relay 模式。
- **Desktop**：
  - 无 Relay + Telegram 已配置时允许启动 Agent，就绪横幅显示“Telegram 本地模式（无需 Relay）”；手机配对禁用并提示“需要手机请先部署 Relay”。
  - 设置页/向导显示本地模式说明；版本 0.5.1。
- 文档：README / Bot 文档说明“Relay 可选：只用 Telegram 不需要”。

## 3. 测试

- Desktop：**45 passed** + `_smoke` **129 项**（本地模式启动/横幅/配对禁用等）。
- 安装包：0.5.1 构建、bots 模块在、无 qq、无作者域名（构建脚本检查）；未在本机安装。
- 未做真实 Telegram/BiliNote 端到端（按用户要求省钱；需用户自己的 token + 本机 BiliNote 验证）。

## 4. 限制

- 本地模式只有 Telegram 入口，没有手机/PWA；任务串行；进度只发“已提交/完成/失败”。
- 本地模式需要本机 BiliNote 引擎可用、LLM Key/转写模型已配置（安装向导完成）。
- Telegram 在中国大陆通常需要代理；Bot 不要公开分享。
