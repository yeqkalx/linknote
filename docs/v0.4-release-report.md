## 2. 功能

- **Telegram（本机长轮询）**：`getMe`、`getUpdates`、私聊全处理、群聊默认只处理 @/命令（可选开启）、完成后发预览 + 完整 `.md` 文件。
- **QQ（本机 WebSocket 网关）**：AppID+AppSecret → access token（7200s 缓存）→ `GET /gateway` → WSS → Identify（`QQBot <at>`, intents `1<<25`）→ 心跳/Resume；支持 C2C 与群 @ 消息、ark 卡片 `jump_url` 解析、被动回复 msg_seq、长笔记分片、窗口关闭转 pending（`/last` 补发）。
- **任务管线复用**：Bot 用 Relay 新增的 `POST /api/v1/agent/devices` 签发独立 device token，然后走现有 `POST /tasks`；同一台电脑的 Agent 处理，完成后从本机 `notes/<task_id>.md` 回发，不经过 Relay 的 bot 服务。
- **桌面对话入口**：设置页“消息入口”卡——Telegram Bot Token / QQ AppID+AppSecret（密码框/掩码）、测试连接、启用开关；保存后写本机 `agent.json` 并重启 Agent。
- **命令**：`/start` `/help` `/status` `/last` `/retry`；本地限流 10 任务/小时/聊天；状态持久化 `bot-state.json`（Telegram offset、QQ session/seq、pending）。
- Bot 凭证只存本机；日志/异常/导出 mask；不提交仓库。

## 4. 未验证 / 已知限制

- 按要求**未做真实 Telegram/QQ/BiliNote 端到端验证**（用户在桌面填凭证后自行验证）。
- QQ：个人主体暂不支持公开使用（只能自己的群 + 20 个内部体验号，公开需企业/个体户认证）；`GROUP_AND_C2C_EVENT` 需平台授权；被动回复窗口 C2C≈60min/群≈5min，超窗用 `/last`；长笔记会分片/截断提示。
- Telegram：中国大陆直连通常不可用；同一 token 多消费者/Webhook 会 409。
- 任何能给 bot 发消息的人都能使用本机电脑/LLM Key，**不要公开分享 bot**。
- 未做代码签名（用户要求），SmartScreen 会提示未知发布者；分发建议 MSI。
- 用户已在聊天中提供过测试凭证，建议验证完成后在 BotFather `/revoke`、QQ 开放平台重置 AppSecret。
